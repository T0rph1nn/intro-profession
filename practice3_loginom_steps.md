# Практическая работа 3. Аналитика данных и low-code технология

Этот файл фиксирует порядок выполнения третьей практической работы в Loginom по презентации.
Практика выполняется в Loginom, поэтому итоговый рабочий артефакт в самой платформе должен быть пакетом `ФамилияИмя.lgp`.

## Подготовка

1. Открыть Loginom одним из способов:
   - учебный сервер `http://loginom.res.rea.ru/app`;
   - локальная Loginom Community Edition версии не ниже 7.3;
   - демо-сервер `https://demo.loginom.ru/app/` как резервный вариант.
2. Убедиться, что доступен набор данных `transactions_diy.lgd`.
3. Создать новый пакет и сохранить его как `ФамилияИмя.lgp`.
4. В первый модуль добавить компонент `Loginom Data файл`.
5. В мастере настройки выбрать `/data/transactions_diy.lgd`.
6. Выполнить узел и открыть `Быстрый просмотр` выходного порта.

## Блок 1. Топ продаж

1. Переименовать первый модуль в `Топ продаж`.
2. Добавить к исходному узлу визуализатор `Статистика`.
3. В статистике включить расчёт:
   - уникальных значений;
   - порядковых статистик.
4. Проверить основные признаки датасета:
   - период продаж: 26 месяцев;
   - последняя дата: `31.10.2019`;
   - товарных групп: 17;
   - самая многочисленная группа: `Комнатные растения и цветы`.
5. Добавить компонент `Группировка`.
6. Соединить его с импортом продаж.
7. Настроить группировку:
   - зона `Группа`: `Товар`;
   - зона `Показатели`: `Кол-во` и `Сумма`;
   - агрегация: сумма.
8. Выполнить узел и проверить, что получилось `30 566` товаров.
9. Для поиска топовых товаров добавить:
   - `Сортировка` по полю `Сумма` по убыванию;
   - `Фильтр строк` для первых 5 записей.
10. У фильтра строк включить порт управляющих переменных:
    `Другие действия` -> `Показать порт управляющих переменных`.
11. В порту переменных создать переменную:
    - имя и метка: `N`;
    - тип: целый;
    - значение по умолчанию: `5`.
12. В настройке фильтра использовать переменную `N` вместо фиксированного числа.
13. Метку узла фильтра изменить на `Первые N строк`.
14. Выделить узлы `Группировка`, `Сортировка`, `Фильтр строк` и свернуть их в подмодель.
15. Назвать подмодель `Топ N товаров`.
16. В настройке подмодели добавить выходной порт типа `Таблица`.
17. Метку выходного порта назвать `Топ товаров`.
18. Внутри подмодели соединить первый выходной порт фильтра строк с выходным портом подмодели.
19. Добавить входной порт переменных подмодели и создать там переменную `N`.
20. Внутри подмодели соединить порт переменных подмодели с портом управляющих переменных фильтра.

## Повтор расчёта для последних 6 месяцев

1. В модуле `Топ продаж` добавить компонент `Фильтр строк`.
2. Настроить условие для поля `Дата продажи`:
   - последние `6` месяцев;
   - относительно даты `31.10.2019`.
3. Метку узла назвать `Последние 6 месяцев`.
4. Добавить компонент `Выполнение узла`.
5. В настройке выбрать узел `Топ N товаров`.
6. Подать на вход `Выполнение узла` данные из фильтра `Последние 6 месяцев`.
7. Выполнить узел и сравнить результат с топом за весь период.
8. Сохранить пакет `ФамилияИмя.lgp`.

## Блок 2. ABC-XYZ-анализ

1. Создать новый модуль и назвать его `ABC-XYZ-анализ`.
2. В первом модуле у узла с продажами настроить модификатор доступа `Внутренний`.
3. Во втором модуле добавить компонент `Узел-ссылка`.
4. В настройке узла-ссылки указать исходный узел продаж из модуля `Топ продаж`.
5. Подключить библиотеку `Loginom Silver Kit`:
   - перейти к объекту `Ссылки`;
   - нажать `Добавить`;
   - выбрать `/libs/silver_kit/loginom_silver_kit.lgp`.
6. На вкладке производных компонентов добавить узел `ABC-анализ`.
7. Соединить `ABC-анализ` с узлом продаж.
8. Если входной порт красный, открыть настройку порта и задать связи:
   - `Объект` -> `Товар`;
   - `Показатель` -> `Сумма`.
9. В переменных ABC оставить границы по умолчанию:
   - A: 80%;
   - B: 95%;
   - C: рассчитывается автоматически.
10. Добавить узел `XYZ-анализ`.
11. Настроить входной порт XYZ:
    - объект: `Товар`;
    - показатель: `Кол-во`.
12. Соединить результаты ABC и XYZ компонентом `Слияние`.
13. Тип соединения выбрать `Внутреннее соединение` по столбцу `Объект`.
14. Внутреннее соединение нужно потому, что сравнивать сегменты можно только для товаров, которые присутствуют в обоих результатах.
15. В настройке выходного порта слияния переименовать поля:
    - `Объект` -> `Товар`;
    - группу ABC назвать `Группа ABC`;
    - группу XYZ назвать `Группа XYZ`.
16. Свернуть узлы `ABC-анализ`, `XYZ-анализ`, `Слияние` в подмодель.
17. Назвать подмодель `ABC-XYZ-анализ`.
18. Добавить в подмодель выходной порт типа `Таблица`.
19. Соединить выходной порт с узлом слияния внутри подмодели.
20. Добавить визуализатор `Куб`.
21. Настроить ABC-XYZ-матрицу:
    - строки измерений: `Группа ABC`;
    - столбцы измерений: `Группа XYZ`;
    - факты: `Товар`, агрегация по умолчанию.
22. Получить ABC-XYZ-матрицу для всех данных.
23. Получить ABC-XYZ-матрицу для последних 6 месяцев, используя уже созданную логику и принцип `одна логика расчётов всегда в одном месте`.

## Блок 3. Разведочный анализ данных

1. Создать новый модуль `Разведочный анализ данных`.
2. Добавить узел-ссылку на исходные продажи.
3. Открыть визуализатор `Статистика`.
4. Для непрерывных полей `Кол-во` и `Сумма` включить:
   - медиану;
   - межквартильный размах;
   - диаграмму размаха.
5. Зафиксировать наблюдения:
   - максимальное `Кол-во` в чеке: `1100`;
   - максимальная `Сумма` покупки: `213 177`;
   - средняя сумма в чеке: `623,2`.
6. Добавить фильтр строк по условию `Кол-во > 200`.
7. Проверить, что таких записей `53`.
8. Сделать группировку по клиентам:
   - группа: клиент;
   - показатели: сумма `Кол-во` и сумма `Сумма`.
9. В статистике по клиентам зафиксировать максимумы:
   - количество: `5 457`;
   - сумма: `3 887 309`.
10. Добавить фильтр `Клиенты с экстремальными чеками`.
11. Условие фильтра:
    - `Кол-во >= 2000`
    - или `Сумма >= 500000`.
12. Проверить, что таких клиентов `9`.
13. В группировку по клиентам добавить показатель `Дата продажи` с агрегацией `Кол-во уникальных`.
14. Для поиска одновизитников отфильтровать клиентов, у которых количество уникальных дат равно `1`.
15. Проверить, что одновизитников `12 859`.
16. Для расчёта цены продажи добавить перед калькулятором фильтр строк, удаляющий записи с `Кол-во = 0`.
17. Проверить, что такая запись `1`.
18. Добавить компонент `Калькулятор`.
19. Рассчитать цену продажи:
    - `Price = Round(Сумма / Кол-во, 2)`.
20. Добавить группировку по товару для расчёта простой средней цены.
21. Для средневзвешенной цены использовать формулу:
    - `sum(Price * Кол-во) / sum(Кол-во)`;
    - весом является `Кол-во`.

## Задание 4. Дополнительные расчёты для теста

В Loginom нужно построить отдельные фильтры и группировки, чтобы ответить на вопросы из теста:

1. Сколько клиентов потратили `100` рублей и менее за всё время:
   - группировка по клиенту;
   - сумма по `Сумма`;
   - фильтр `Сумма <= 100`;
   - посчитать число строк.
2. Средняя сумма покупки у одновизитника:
   - использовать клиентов с одной уникальной датой продажи;
   - посчитать среднюю сумму покупки;
   - округлить до ближайшего целого.
3. Сколько клиентов совершили более `50` визитов:
   - визит = все чеки клиента в пределах одних суток;
   - группировка по клиенту и дате;
   - затем группировка по клиенту с подсчётом числа дат;
   - фильтр `число визитов > 50`.
4. Сколько товаров имеют среднюю цену `10` рублей и менее:
   - исключить записи с `Кол-во = 0`;
   - рассчитать `Price = Сумма / Кол-во`;
   - сгруппировать по товару;
   - взять простое среднее `Price`;
   - отфильтровать `Price <= 10`.

## Задание 5. Изменение ABC-XYZ-сегмента

1. Получить ABC-XYZ-сегменты для всего периода.
2. Получить ABC-XYZ-сегменты для последних 6 месяцев.
3. Соединить две таблицы внутренним соединением по `Товар`.
4. Внутреннее соединение нужно, потому что сравниваются только товары, которые продавались в обоих периодах.
5. Добавить фильтр строк:
   - `Группа ABC весь период != Группа ABC последние 6 месяцев`
   - или `Группа XYZ весь период != Группа XYZ последние 6 месяцев`.
6. Количество строк после фильтра — это ответ на вопрос о товарах, у которых изменился сегмент.
